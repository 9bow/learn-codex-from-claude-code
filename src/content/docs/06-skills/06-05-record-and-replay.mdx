## Record & Replay란

Record & Replay는 사용자가 Mac에서 이미 알고 있는 작업을 한 번 시연하면, ChatGPT 또는 Codex가 그 흐름을 분석해 재사용 가능한 skill 초안을 만드는 기능입니다. 반복적이고 성공 기준이 명확하지만 말로 설명하기 번거로운 업무에 적합합니다.

공식 문서 기준으로 이 기능은 macOS에서 사용할 수 있고 Computer Use가 활성화되어 있어야 합니다. 모든 화면 자동화를 대체하는 기능은 아니며, 기록 중에는 필요한 창 내용과 동작이 관찰될 수 있으므로 다루는 정보의 민감도를 먼저 판단해야 합니다.

```text
안정된 수동 업무
      │
      ▼
기록할 범위·비밀값·승인 지점 점검
      │
      ▼
Record & Replay로 한 번 시연
      │
      ▼
skill 초안 생성 ── 검토 · 수정 · 제한된 테스트
      │
      ▼
반복 업무에 재사용
```

## 언제 쓰는가

다음과 같이 절차는 안정되어 있지만 팀마다 선호하는 방식이 다른 작업이 좋은 후보입니다.

- 정해진 형식으로 이슈를 만들고 담당자·레이블을 지정하는 일
- 매주 같은 보고서를 다운로드하고 검토용 요약을 만드는 일
- 특정 서비스의 관리 화면에서 반복 상태를 확인하는 일

반대로 성공 기준이 아직 불명확하거나, 매번 다른 판단이 필요한 업무는 먼저 일반 프롬프트나 수동 절차로 다듬습니다. 불완전한 과정을 그대로 기록하면 불완전한 skill을 더 빠르게 반복하게 됩니다.

## 기록과 검토 절차

1. 완료 상태와 필요한 입력을 한 문장으로 정리합니다.
2. 개인 정보, API 키, 결제 화면, 관리자 권한처럼 기록하면 안 되는 화면을 제외합니다.
3. ChatGPT 데스크톱 앱에서 Codex 또는 Work를 열고 Plugins의 기록 기능을 시작합니다.
4. 한 가지 업무만 끝까지 시연한 뒤 기록을 멈춥니다.
5. 생성된 `SKILL.md` 초안에서 발동 조건, 입력, 단계, 검증 기준을 읽고 수정합니다.

<ConceptCard title="자동 생성된 skill도 코드처럼 검토한다">
기록 결과는 초안입니다. 스크립트, browser/computer use, plugin, 외부 연결이 포함되었다면 실행 범위와 권한 요청을 확인합니다. 특히 전송·게시·삭제 같은 외부 변경은 사용자가 매번 확인할 수 있게 남겨 두는 편이 안전합니다.
</ConceptCard>

## 수동 작성과의 선택

| 상황 | 더 적합한 방식 |
| --- | --- |
| 절차를 글과 코드로 명확히 설명할 수 있음 | `SKILL.md`를 수동 작성 |
| 화면 조작 순서가 핵심이고 이미 안정적임 | Record & Replay로 초안 생성 |
| 팀 공통 규칙과 테스트 스크립트가 필요함 | 수동 작성 후 Git 리뷰 |
| 민감한 정보·고위험 승인 화면이 포함됨 | 기록하지 않고 최소 권한 절차로 재설계 |

## 핵심 정리

- Record & Replay는 안정된 업무를 한 번 시연해 skill 초안을 만드는 기능입니다.
- macOS와 활성화된 Computer Use가 필요하며, 기록 범위에 보이는 정보와 권한을 먼저 점검합니다.
- 초안은 발동 조건, 입력, 외부 변경, 검증 절차를 검토·수정한 뒤 사용합니다.
