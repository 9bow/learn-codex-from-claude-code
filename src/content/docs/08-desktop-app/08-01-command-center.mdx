## 제품명과 역할

현재 공식 문서는 제품명을 **ChatGPT desktop app**으로 사용합니다. 이 앱 안에서 Chat, Work, Codex를 선택할 수 있습니다. 따라서 이전 문서나 설치 화면에서 "Codex app"이라는 이름을 보더라도, Codex 작업 흐름 자체가 사라졌다고 이해하면 안 됩니다.

앱은 여러 프로젝트와 긴 작업을 한 화면에서 살피고, 파일·문서·이미지·diff를 검토하는 데 적합합니다. 반면 빠른 터미널 작업과 스크립트 자동화는 CLI가 더 자연스럽고, 열린 코드 옆에서의 짧은 반복은 IDE 확장이 편할 수 있습니다.

```text
프로젝트와 파일 선택
        │
        ▼
ChatGPT desktop app
 ├─ Chat / Work / Codex 대화
 ├─ 프로젝트·스레드·파일 검토
 ├─ 브라우저·컴퓨터·plugin 사용
 └─ 예약 작업과 결과 확인
```

## 주요 작업 흐름

| 기능 | 사용할 때 | 주의할 점 |
| --- | --- | --- |
| 프로젝트와 채팅 | 관련 파일·결정을 같은 맥락에 둘 때 | 독립 작업은 별도 채팅으로 분리 |
| 파일·diff 검토 | 변경 전후를 눈으로 확인할 때 | Git 상태와 테스트 결과도 함께 확인 |
| 하위 에이전트 | 탐색·테스트처럼 독립적인 일이 있을 때 | 같은 파일을 동시에 수정하지 않기 |
| browser·computer use | 로그인된 화면이나 데스크톱 앱 조작이 필요할 때 | 권한과 외부 전송 범위를 검토 |
| 예약 작업 | 반복되는 안정된 업무 | 로컬 파일을 쓰면 컴퓨터와 앱이 켜져 있어야 함 |

## 플랫폼과 로그인

공식 설치 안내는 macOS, Windows, Linux용 ChatGPT 데스크톱 앱을 제공합니다. 사용 가능한 모델, Work 기능, plugin, computer use는 운영체제만이 아니라 계정·플랜·워크스페이스 정책에도 영향을 받습니다. 설치 파일명이나 화면 구성이 바뀔 수 있으므로, 플랫폼 지원을 고정 날짜 표로 보관하지 말고 공식 앱 안내를 확인합니다.

앱을 열고 ChatGPT 계정으로 로그인한 뒤, 대화·프로젝트·폴더 중 작업 위치를 선택합니다. API 키와 외부 연결의 지원 범위는 별도 정책을 따르므로 [03-02 인증](/learn-codex-from-claude-code/03-install/03-02-auth-chatgpt-vs-api/)에서 확인합니다.

## 예약 작업과 로컬 파일

예약 작업(scheduled task)은 반복되는 일을 백그라운드에서 실행합니다. ChatGPT 데스크톱 앱에서는 로컬 프로젝트에 연결된 작업을 프로젝트 디렉터리 또는 격리된 worktree에서 실행할 수 있습니다. 로컬 파일이 필요한 예약 작업은 컴퓨터와 앱이 켜져 있어야 합니다.

웹에서 실행하는 예약 작업은 업로드한 자료와 연결된 도구를 사용할 수 있지만, 내 컴퓨터의 폴더나 worktree를 지속적으로 유지하지는 않습니다. Codex CLI와 IDE extension은 예약 작업을 관리하는 화면을 제공하지 않으므로, 작업 프롬프트·skill·스크립트를 준비하거나 검증하는 용도로 사용합니다.

<ConceptCard title="예약하기 전에 확인할 것">
반복 실행 전에 수동으로 최소 두 번 이상 성공한 절차인지 확인합니다. 작업의 입력, 외부 전송, 파일 쓰기 범위, 실패 시 알림, 사람이 검토할 산출물을 정해야 합니다. 불안정한 절차를 먼저 예약하면 오류를 더 자주 반복할 뿐입니다.
</ConceptCard>

## 핵심 정리

- 현재 제품명은 ChatGPT desktop app이며, 그 안에서 Codex 작업을 시작합니다.
- 앱은 프로젝트·스레드·파일·병렬 작업을 함께 검토하는 작업 공간입니다.
- macOS, Windows, Linux 지원과 기능 가용성은 공식 설치 안내와 현재 계정 화면으로 확인합니다.
- 로컬 프로젝트 예약 작업은 프로젝트 디렉터리 또는 worktree에서 실행될 수 있고, 로컬 환경이 켜져 있어야 합니다.
